# 🌱 Plant-Based Energy Drink Formulator

A comprehensive web application for creating the world's healthiest plant-based energy drink with perfect taste and optimal nutrition.

## Features

### 1. Recipe Formulation Calculator
- Add ingredients with precise measurements
- Real-time calculation of:
  - Total volume
  - Total cost
  - Calories
  - Caffeine content
  - Sugar, protein, and vitamins
- Save and manage multiple recipes
- Remove ingredients easily

### 2. Ingredient Database
- Comprehensive database of plant-based ingredients:
  - **Energy Sources**: Green tea, Yerba mate, Guarana, Ginseng
  - **Flavor Enhancers**: Citrus extracts, Ginger, Mint
  - **Electrolytes**: Coconut water, Sea salt, Magnesium citrate
  - **Natural Sweeteners**: Stevia, Monk fruit, Agave nectar
  - **Vitamins & Antioxidants**: B-complex, Vitamin C, CoQ10
- Search and filter functionality
- Detailed properties for each ingredient

### 3. Nutrition Analyzer
- Input nutrition data for any recipe
- Get detailed analysis including:
  - Per 100ml breakdown
  - Health assessments
  - Recommendations for optimization
  - Warnings for high sugar/calories

### 4. Research & Comprehensive Guide
- Complete guide to plant-based energy sources
- Flavor optimization tips
- Packaging information (paper cup with aluminum foil)
- Optimal recipe formulation strategy
- Health benefits summary

## How to Use

### On Desktop/Computer:
1. **Open the Application**
   - Simply open `index.html` in any modern web browser
   - No server or installation required!

### On iPhone (Install as App):
1. **See INSTALL_IPHONE.md** for detailed instructions
2. **Quick Steps**:
   - Host the files on a web server (GitHub Pages, Netlify, etc.)
   - Open in Safari on iPhone
   - Tap Share button → "Add to Home Screen"
   - App will appear on your home screen!

2. **Create a Recipe**
   - Go to the "Recipe Calculator" tab
   - Select an ingredient from the dropdown
   - Enter the amount (ml or grams)
   - Click "Add to Recipe"
   - Watch real-time stats update

3. **Browse Ingredients**
   - Go to the "Ingredient Database" tab
   - Search by name or filter by category
   - View detailed properties of each ingredient

4. **Analyze Nutrition**
   - Go to the "Nutrition Analyzer" tab
   - Enter your recipe's nutrition data
   - Click "Analyze Nutrition" for detailed insights

5. **Learn More**
   - Check the "Research & Guide" tab for comprehensive information
   - Learn about optimal formulations
   - Understand packaging options

## Packaging Information

The application includes detailed information about using **paper cups with aluminum foil lining** for optimal drink preservation:
- Eco-friendly and sustainable
- Excellent thermal barrier
- Keeps drinks cold longer
- Maintains drink quality

## Target Nutrition Profile

For the world's healthiest energy drink (per 250ml):
- **Calories**: 10-30 (low calorie)
- **Caffeine**: 80-150mg (moderate, sustained release)
- **Sugar**: 0-5g (minimal, from natural sources only)
- **Vitamins**: 50-100% RDA of B-complex, C
- **Electrolytes**: Balanced sodium, potassium, magnesium
