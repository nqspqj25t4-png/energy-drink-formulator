# 🚀 Quick iPhone Installation Guide

## Easiest Method (5 minutes):

### Step 1: Create Icons
1. Open `create-icons.html` in your browser
2. Click "Download 192x192" and "Download 512x512"
3. Save both files in the same folder as `index.html`

### Step 2: Host Your App (Choose one):

**Option A: GitHub Pages (Recommended - Free)**
1. Go to [github.com](https://github.com) and sign up/login
2. Click the "+" icon → "New repository"
3. Name it: `energy-drink-formulator`
4. Click "Create repository"
5. Drag and drop ALL files from the folder into GitHub
6. Click "Commit changes"
7. Go to Settings → Pages
8. Under "Source", select "main" branch
9. Click "Save"
10. Wait 2 minutes, then visit: `https://YOUR-USERNAME.github.io/energy-drink-formulator/`

**Option B: Netlify (Even Easier - Free)**
1. Go to [netlify.com](https://netlify.com) and sign up
2. Drag and drop your entire folder onto the Netlify page
3. Get instant URL (e.g., `https://random-name-123.netlify.app`)
4. Done!

### Step 3: Install on iPhone
1. Open Safari on your iPhone (NOT Chrome!)
2. Go to your app URL (from Step 2)
3. Tap the Share button (square with arrow) at bottom
4. Scroll down and tap "Add to Home Screen"
5. Tap "Add"
6. Done! App icon appears on home screen! 🎉

## That's it! Your app is now installed on iPhone!

The app will:
- ✅ Open in full-screen (no browser bars)
- ✅ Work offline after first visit
- ✅ Have its own icon
- ✅ Feel like a native app

---

**Troubleshooting:**
- If "Add to Home Screen" doesn't appear, make sure you're using Safari
- Make sure you're accessing from a web server (not file://)
- Try refreshing the page
